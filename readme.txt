The fastest WordPress appointment booking platform. Paystack-native, Flutterwave-native, WhatsApp-native, Elementor-first.

== Description ==

Bookora is a premium WordPress appointment booking platform built for speed, local payment rails, and the messaging channels customers actually use.

This release (0.1.0) is the **Stage 1 — Project Foundation** build: plugin bootstrap, custom database schema with a migration system, service container, repository layer, settings, REST API framework, logging, and the admin dashboard shell. Booking modules ship in subsequent stages.

== Installation ==

1. Upload the `bookora` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open the **Bookora** menu in wp-admin.
